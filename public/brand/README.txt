Brand files
===========
logo.svg    - shown top-left on every page and on the sign-in page
banner.svg  - wide banner strip under the header (about 1600x220, the left half stays visible on phones)

These two files are neutral stand-ins (a plain text wordmark and a gradient). To use the official Melbet
logo and banner, replace them with the real artwork under the SAME file names (logo.svg / banner.svg),
or change the two paths in index.html if you only have PNG/JPG. Colours are CSS variables at the top of
style.css (--brand is the yellow).
